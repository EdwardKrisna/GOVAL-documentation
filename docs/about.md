# About GOVAL

## Geospatial Optimization & Validation Analytics Library

GOVAL is a collection of geospatial optimization and analytics projects for Indonesian metropolitan areas, focusing on property valuation, facility placement optimization, and spatial analysis.

## Mission

To provide data-driven solutions for urban planning and real estate analytics using advanced geospatial methods, machine learning, and optimization techniques.

## Projects

### Current

- **Jabodetabek Property Valuation Model v4** - Feature engineering pipeline for property price prediction

### Planned

- **Bandung** - Property valuation and spatial optimization
- **Surabaya** - Urban analytics and optimization

## Technology

GOVAL leverages modern Python libraries for geospatial analysis, machine learning, and optimization:

- GeoPandas & Shapely for spatial operations
- Scikit-learn for machine learning
- PuLP/OR-Tools for optimization
- Folium & Matplotlib for visualization
