## 🛠️ Technology Stack

- **Python 3.8+**
- **Core Libraries:** pandas, numpy, scikit-learn
- **Geospatial:** geopandas, shapely, pyproj
- **Optimization:** scipy, PuLP/OR-Tools
- **Visualization:** matplotlib, folium, contextily
